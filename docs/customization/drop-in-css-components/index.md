These are CSS components that can be relatively easily dropped in and should not conflict with Digital Garden Template updates.

These components may be added to `src/site/styles/custom-style.scss`[^1] or in `src/site/includes/components/user/...` as described in [Adding custom components](https://dg-docs.ole.dev/advanced/adding-custom-components/).

[^1]: Which is deprecated, but still supported.
