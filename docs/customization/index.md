Digital Garden is pretty flexible, and you can easily add custom features that make it truly your own.

All of these guides rely on you being able to add or modify code directly to your repository; at some point we will create a guide, but for now, you can either do it to the files directly in GitHub, or use a tool like [GitHub Desktop](https://desktop.github.com/download/) to clone and modify your repo.
